# ReadX 功能介绍

ReadX 是一个面向科研阅读的本地桌面工作区，支持 Windows 与 macOS。它把论文的导入、识别、翻译、双语阅读、批注、AI 问答、结构化精读与演示稿生成整合在同一个应用内；论文文件、书库数据与阅读记录保存在本机。

本文档按模块说明 ReadX 的现有功能，措辞以代码实现为准。界面预览与配图见文末「附录 B」。

---

## 1. 文献库（Library）

- **入库格式**：PDF 与无 DRM 的可重排 EPUB。PDF 以文件内容哈希作为唯一标识，重复导入同一文件不会产生副本。
- **组织方式**：书架、收藏、标签（每篇 ≤16 个）、分类（每篇 ≤8 个，带颜色）、回收站（软删除，可恢复或永久清除）。
- **阅读状态**：队列 / 正在阅读 / 已精读 / 归档四种；其中前三者由对话、批注、精读记录自动推导，归档为手动设置。
- **检索**：按标题、作者、会场进行不区分大小写的子串匹配（非模糊/语义搜索）。
- **视图**：网格 / 列表 / 表格三种布局；顶部统计当前文献、正在阅读、已精读数量。
- **每日推荐**：侧栏汇总近期新论文，来源为 OpenAlex，按会议白名单与年份排序（依赖联网）。
- **其他入口**：知识图谱、阅读日历（按天聚合最近阅读活动）。

## 2. 导入与元数据识别（Import）

- **导入途径**：本地文件选择、整窗拖拽、公开 PDF/EPUB 直链、arXiv 编号或链接、DOI，以及按标题检索后选择全文。
- **批量限制**：单次最多 16 个文件；单个 PDF 上限 50 MB、≤1000 页。
- **元数据识别**：导入后由所配置的 AI 渠道从首页文本识别题名、作者、期刊/会议、年份、DOI 与中文题名；未知字段留空，不以文件名冒充题目。题录查找以 OpenAlex 为主、Crossref 为备。
- **进度可见**：导入面板实时显示当前文件序号、解析页数、上传字节、翻译段数与批次、保存阶段、总用时及带时间的处理记录；不可计量的阶段显示等待动画而非伪造百分比。可随时取消，未完成项不生成书库条目。

## 3. 处理流水线（OCR · 翻译 · 渲染 · 记忆）

导入后的 PDF 依次经过四个阶段，状态分开展示：

1. **OCR / 版面识别**：调用远程 PaddleOCR 服务，输出归一化的版面块（正文、标题、图注、公式、表格等）与坐标。结果按原 PDF 内容哈希缓存在本机，翻页不重复提交。
2. **翻译**：使用所配置的 AI 渠道逐段翻译为简体中文；相邻块注入消歧上下文，含术语保护、占位符保护、确定性质检与失败修复（分批递归拆分、乱码重建、Agent 修复、最终未译恢复）。译文按段落哈希缓存，重新导入可复用。
3. **渲染**：内置排版引擎将译文叠加回原页对应文字块，保留页尺寸、栏位与图表/公式的原始像素，产出整本译文 PDF；也支持单页按需渲染。
4. **论文记忆**：生成一份带页码的结构化阅读地图，供后续问答与精读复用，避免重复读取原文。

任务状态包括 处理中 / 已完成 / 失败 / 已取消 / 已中断；进度按阶段以「页 / 段」计数并持久化，进程重启后可续看。**注意：OCR 与翻译均需联网，且导入前必须同时配置好 AI 渠道与 OCR 令牌，缺任一导入直接失败。**

## 4. 阅读器（Reading）

- **双语对照**：原文页与译文页左右并排、逐页同步；双栏论文按原文版面呈现，译文与页面位置对应。可在「仅原文 / 原文译文 / 仅译文」间切换，分隔条可拖动、可交换左右。
- **导航**：左侧章节目录（优先使用 PDF 书签，缺失时从正文补充），点击定位并高亮；滚动时实时高亮当前章节；支持页码输入与上/下页。
- **缩放**：50%–300%，支持适合宽度；连续滚动 + 懒渲染。
- **位置恢复**：PDF 保存页码、EPUB 保存章节，重新打开自动回到上次位置。
- **导出**：可将当前文档导出为译文 PDF。

## 5. 高亮与批注（Annotations）

- **选区操作**：鼠标拖选原文后可添加高亮、下划线或问题批注，填写笔记、选择颜色（琥珀/玫红/天蓝/青绿/紫）与标签。
- **段落操作**：悬停显示段落边框，点击段落可「询问助教」或跳转双语对照位置。
- **管理**：右栏支持修改、按类型/颜色筛选、定位到正文，并可整体导出为 Markdown。
- **存储**：批注保存在本机数据库，不外链进原 PDF 文件本身。

## 6. AI 助教（Assistant）

- **上下文问答**：围绕当前论文提问，默认附带论文上下文；回答按相关性从全文选取若干页（界面标注「原文范围：N/M 页 · 仅相关片段」），而非整篇塞入。
- **出处引用**：回答中的 `Page N` / `Chapter N` 会渲染为可点击标记，点击跳回原文对应页。
- **证据约束**：系统提示要求区分「论文事实」与「AI 推断」、标注节号/图表号/页码、查不到即答「论文中未找到」，并忽略论文正文内嵌的指令（防提示注入）。
- **附件**：支持附加文本文件（≤3 个、合计 ≤16000 字符）与图片（≤4 张）；图片理解取决于所选渠道（部分 CLI 渠道不支持图片）。
- **会话管理**：每篇文献可建立多个本机对话，支持停止、重新回答、复制；失败或被中断的回答不进入后续上下文。
- **模型与推理强度**：输入区可选择模型与离散推理强度档位，选择自动保存并用于后续对话与精读。

## 7. 精读五重奏（Deep Reading）

将一篇论文的精读拆为五个独立章节，各自生成、各自保存：

| 序号 | 章节 | 关注点 |
| --- | --- | --- |
| 01 | 实验动机 | 研究问题、既有局限、核心假设与贡献边界 |
| 02 | 方法公式 | 数据流、约束、关键公式与适用条件 |
| 03 | 实验配置 | 数据集、训练/实施条件、基线与指标 |
| 04 | 结果分析 | 结果表、消融、泛化、效率与待核对项 |
| 05 | 代码复现 | 资源、环境、成本、缺失与复现行动清单 |

- 支持逐节生成、生成剩余项、停止、继续、复制与导出 Markdown；每节完成后可「向助教追问」。
- 生成结果附页码与公式引用，可点击回原文核对；无法核验的重新生成结果不覆盖原记录。
- 「代码复现」在论文未提供代码链接时会明确跳过，不臆造。
- 各章节按小节顺序生成并即时落库，中途停止保留已完成部分。

## 8. 论文演示稿（Presentation Studio）

- **流程**：在独立工作区选择书库论文 →「生成学术演示稿」→ 先通读全文，再规划页面，最后构建幻灯片；三阶段带进度显示，边生成边预览。
- **版式**：六种学术版式（重点陈述、对比、流程、图文证据、数据指标、聚焦观点），由内容决定，避免连续重复。
- **图表**：原文图表按比例嵌入对应论证页，不做裁剪或拉伸。
- **模板**：内置模板，也可上传自定义 `.pptx` 模板（≤80 MiB）供其学习配色与信息层级。
- **导出**：生成可编辑的 `.pptx` 文件，完整来源保留在讲者备注中；中英文用微软雅黑、数字用 Times New Roman。
- **说明**：应用内的幻灯片预览为只读画布，进一步编辑需在导出的 `.pptx` 中进行。

## 9. AI 助手设置（Settings）

- **服务商预设**：内置 DeepSeek、Kimi、通义千问、智谱 GLM、硅基流动、火山方舟、OpenAI、Anthropic、OpenRouter、本机 Ollama、本机 LM Studio、Codex Desktop/CLI、WorkBuddy、Claude Code CLI、Kimi Code CLI 及自定义服务端点。
- **接入方式**：API 渠道填写服务地址、模型名与 API Key；CLI 渠道（Codex / Claude Code / Kimi Code）复用本机已有登录态，不读取凭据文件。
- **两步配置**：第 1 步连接服务商（模型、推理强度、译前准备档位、测试连接）；第 2 步配置文档识别（PaddleOCR 令牌与服务地址）。
- **密钥存放**：API Key 与 OCR 令牌保存在本机配置文件，不回传界面；不同渠道与地址分别保留各自的 Key。

## 10. 平台与安装

- **技术栈**：Electron 桌面壳 + Go 本地服务 + React/PDF.js 界面 + SQLite；随包内置 Python、Typst 与字体等运行时，普通用户无需另装开发工具。
- **安装包**：Windows 提供 x64 NSIS 安装程序；macOS 提供 DMG 与 ZIP。
- **数据位置**：Windows 位于 `%APPDATA%\ReadX`，macOS 位于 `~/Library/Application Support/ReadX`；论文与译文存于 `library/`，数据库位于 `app/data/v2/reader.db`。
- **网络边界**：书库管理、阅读、批注与译文渲染在本机进行；OCR、翻译与 AI 问答会把相关文本/图片发送给用户所配置的服务商，每日推荐依赖外网检索。

## 附录 A：当前边界与已知限制

以下按 v1.0.3 与当前开发代码核对；开发中新能力见单独说明：

- 当前开发代码支持文件队列「仅保存原文」，无需 AI / OCR 配置；自动 OCR 和全文翻译仍依赖所配置服务，链接检索与下载仍需联网。
- 检索为子串匹配，无模糊/语义搜索；无跨论文「问整个书库」的能力。
- Windows v1.0.3 支持通过 WebDAV 或网盘本地同步文件夹同步书库、进度和笔记，并保留冲突版本；同步不等于完整备份。无多人实时协作或云端账号。
- 翻译目标语言固定为简体中文，暂无目标语言选项。
- 导出仅两种：译文 PDF 与批注 Markdown；无论文 DOCX/Markdown 导出。
- 公式与表格在原页中保持原样，不参与重排。
- 演示稿预览只读；精读五重奏按小节顺序生成，非并发。
- 知识图谱需逐篇手动抽取，非全库自动构建。
- EPUB 支持阅读、批注、翻译与按章节问答，但不支持精读五重奏、双语译文视图与译文 PDF 导出。
- 已提供全库全文检索（显示索引覆盖）、文档内查找，以及本机 Zotero PDF 批量导入；无界面语言切换（全中文）、移动端或 PDF 密码输入。
- 安装包未做代码签名/公证；Windows 当前发布版本为 v1.0.3，仍在迭代。
