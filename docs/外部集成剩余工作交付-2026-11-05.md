## 使用顺序

### Zotero

1. 启动支持本机 API 的 Zotero；迁移和回写流程要求提供实例 ID 的新版客户端，本机写入依据 [Zotero 10+ 本机 API](https://www.zotero.org/support/dev/web_api/v3/local_api)。
2. 在 Zotero 设置中启用本机 API，在 ReadX 原有 Zotero 面板读取个人库集合／笔记快照。
3. 在新增迁移面板点击“迁入／重试当前快照”。此操作只复制本机资料，不调用 AI 或 OCR；中断后可重试。状态为 `partial` 或 `interrupted` 时查看附件错误，不能按完整迁移验收。
4. 可导出 ZIP 检查原始对象、集合父子关系、原生批注定位和非 PDF 附件。此为私人资料迁移档案，**不是过滤后的只读分享文件**。
5. 勾选至多 100 个对象，点击核对。只读核对不修改 Zotero。可编辑本地镜像，也可在书库／阅读器修改已映射内容。
6. 每个有差异的对象显示两端内容。采用 Zotero 会更新本地；采用 ReadX 需要 Zotero 本机写授权和 ReadX 的发送许可。版本或本地编辑变化时旧计划会拒绝应用，需重新核对。

权限范围包含仍保留的历史论文；来源后来不再列出某个 PDF，不会使其退出集合的禁发范围。完整快照取消原有 5,000 对象硬上限，按 100 条分页读至结束；超时／失败不保存截断快照。

### 检索与分享

检索下一页会沿用原会话和原表达式。可切换“本会话所有已抓取页”，选择结果加入待读和工作台；导出的是包含页记录与来源信息的会话。已抓取结果去重不等于全部来源唯一命中数。未下载题录不会伪装成已经入库的文献。

分享默认只含题录。原文、批注、精读、研究想法和对照各自勾选。只包含有证据关联所选论文的研究想法，并过滤其未选择论文的证据；想法正文仍是用户原有判断，不承诺自动脱敏。EPUB 采用结构化原文展示，不复刻原版式；PNG/JPEG/GIF/WebP 可预览，其他图片提示下载原 EPUB，完整资源仍在所附原文件中。
