## 环境和数据

- Windows 上启动项目构建的 Electron 44.2.0 与 Go 服务，使用独立数据根、Electron profile、合成的两页 PDF 和单章 EPUB。没有操作用户已安装的 ReadX 书库。
- Zotero 10.0.7 来自官方 Windows ZIP，使用独立 profile 和资料目录，关闭自动同步，不登录账号。通过其 Connector API 写入合成期刊论文、笔记和 PDF，随后由 ReadX 界面读取、迁移。
- 原生窗口可读取控件树，书库筛选通过 UI Automation 验证。但截图持续报捕获超时、鼠标操作缺少几何信息；Zotero 窗口还出现归属校验异常。后续点击验收使用同一构建的正常 HTTP 应用页面。浏览器界面验收不替代 Electron 全流程点击或安装包验收。
- 可重复建立新隔离环境的脚本：`windows/scripts/acceptance-runtime.mjs`。需先完成项目构建及 Electron 依赖安装；该脚本不安装扩展、不注册系统协议，也不自动启动 Zotero。

## 发现并修复的 bug

窄窗口中，点击“更多书库操作”下的“只读分享”或“导出书目”，菜单消失但目标对话框不打开。两条操作均复现。

`LibraryScreen.tsx` 在菜单的 `onClickCapture` 中立即关闭菜单，导致子按钮卸载，操作未执行。Windows 和 macOS 同时改为冒泡阶段的 `onClick`，使子按钮先处理动作，再关闭菜单。

重新构建后通过浏览器界面复验：两个对话框都能打开，分享完成实际授权、下载和内容核验。Windows 网页类型检查与生产构建通过；macOS 对应源码同步，不称作 macOS 实机验证。
