# ReadX 浏览器采集开发版

1. 构建并启动当前 ReadX 桌面代码；打开「导入文档 → 浏览器采集收件箱 → 启用浏览器接收」。
2. 在 Chrome／Edge 扩展管理页开启开发者模式，选择「加载已解压的扩展」，指向本目录。
3. 打开论文页面，点击扩展的「保存当前论文来源」。浏览器可能要求确认打开 ReadX。
4. ReadX 提示保存成功后，在采集收件箱选择下载。采集本身不会自动执行题录补全、OCR 或翻译。

使用独立 `readx-capture` 系统协议，不向扩展提供后端 Bearer Token；收到的输入仍在桌面和服务端校验。只使用点击时的 `activeTab` 和 `scripting` 权限，不申请全部网站、Cookie 或浏览历史权限。浏览器内置 PDF 页不允许脚本提取时，只保留来源 URL 和标签页标题。

这是未上架的开发版，尚未完成 Chrome／Edge 与两端安装包的真实协议唤起验证。macOS 源码模式可能需要已打包并注册的应用；不承诺下载订阅全文。协议处理只保存本地候选，不会执行页面传来的任意 API、命令或脚本。
