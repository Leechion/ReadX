# 完整备份与恢复

本功能属于当前开发代码，尚未发布到 v1.0.3 安装包。入口位于书库的同步设置面板，提供「创建完整备份」和「从备份恢复」。需要独立桌面模式；纯浏览器或连接外部后端的开发模式不能通过此入口执行停机操作。

## 创建备份

1. 点击「创建完整备份」，选择数据目录之外的保存位置。
2. 确认后，应用采集当前界面的本地存储，并关闭桌面端和自有后端。
3. 后台进程等待两者退出，将数据和桌面配置复制到新的 `ReadX-backup-*` 文件夹，校验文件与数据库，然后自动重新启动应用并显示结果。

备份包含数据根及 Electron `userData` 中的用户数据，包括原文、数据库、生成产物、LaTeX 项目和快照，以及本地研究工作台、聊天、图表选区和独立文库。数据库引用的数据目录之外的 PDF/EPUB 也会另行归档；缺失的原文件会导致备份失败，不会被静默跳过。临时浏览器缓存与进程锁不归档；数据树中的符号链接会明确报错，需要先把对应内容复制进数据目录。

备份文件夹包含版本清单 `manifest.json`、文件大小和 SHA-256 校验值，以及用于跨端口恢复的浏览器存储快照。此格式不压缩；迁移时需要复制整个文件夹。备份可能包含 API 密钥与个人笔记，应保存在自己控制的位置。系统加密保存的密码不保证能在另一台机器解密。

## 从备份恢复

1. 点击「从备份恢复」，选择包含 `manifest.json` 的备份文件夹。
2. 应用先核验格式、文件校验值与 SQLite 完整性，再显示替换确认。
3. 确认后关闭应用，在当前数据目录旁准备恢复副本，迁移数据库及 JSON 配置中的原数据根路径，并把外部附件放入新数据根的 `library/backup-assets`。
4. 文件准备成功后才替换当前目录。原目录保留为旁边的 `*.before-restore-*` 检查点；替换中途失败时尝试将当前目录回滚。
5. 自动重启后，在挂载工作区前恢复当前页面来源下的 Local Storage 和 IndexedDB，包括图片 Blob、章节、索引及数据库版本。成功后才删除待恢复快照；失败时保留快照并显示重试提示。

恢复会替换当前数据，不与当前书库合并。自定义 `CBCT_DATA_ROOT` 与 Electron 配置目录不同时，两处都会恢复。数据库与配置中的路径会迁移到当前目录；系统凭据及平台相关的外部运行时需要在新机器重新配置。恢复前的桌面存储快照也保留在原配置目录的检查点内。

## 检查点与失败处理

- 校验失败：不替换当前书库，先检查备份是否复制完整。
- 创建失败：删除未完成的临时备份，重启时显示具体原因。
- 替换失败：回滚已替换目录；保留检查点以便手动恢复。
- 手动退回检查点：关闭应用，先另存当前目录，再把对应检查点改回原目录名称。使用独立数据根时，数据目录和桌面配置目录应一起退回。
- 检查点不会自动清理。确认恢复后的论文、笔记与项目正确后，再自行决定是否删除旧数据。

## 开发验证

在 `windows` 目录执行 `npm run test:backup`：构建共享类型和桌面代码，验证文件归档、路径迁移、WAL 记录、完整性校验、目录回滚、等待退出与重启调度，以及浏览器存储的往返恢复。

浏览器存储测试使用 fake-indexeddb，后台调度测试使用独立 Node 进程。本机尚未完成真实 Electron 窗口与安装包的端到端操作；macOS 代码同步交付，但没有在 macOS 实机验证。
