## 本轮实现

Windows 与 macOS 的文件队列增加「仅保存原文」，支持单篇和批量导入。此分支复用已有文件保存、题录、去重及回收站恢复逻辑，明确跳过在线题录补全、OCR、翻译和论文记忆生成。已有题录随文件保留；无题录时使用文件名，不推断作者、期刊或年份。

入库后可阅读及批注；有文字层的 PDF 仍由阅读器现有流程补建正文索引。扫描件不进行 OCR。后续配置服务后，复用阅读器「重新翻译」入口：缺少识别结果时重新 OCR，再翻译，不新建书库条目。链接搜索和下载仍需网络。

默认完整处理流程保持原行为。新增回归测试直接调用真实 HTTP 上传接口，在无 AI/OCR 配置下验证入库、原文件取回及重复导入；另运行普通处理前置条件与 EPUB 相关回归测试。

## 完整备份必须覆盖的已发现存储

| 存储 | 位置与恢复约束 |
| --- | --- |
| SQLite 权威数据 | `<数据根>/app/data/v2/reader.db`；使用 WAL，不能在运行中仅复制主文件冒充一致快照 |
| 原文与生成文件 | `<数据根>/library` 及 `app/data`；需要枚举数据库引用的译文、精读、LaTeX 项目及快照等文件 |
| 浏览器持久化数据 | Electron `userData` 下的 Local Storage、IndexedDB 等；研究工作台、聊天和手动图表选区等状态不能只靠服务端数据库恢复 |
| 独立文库 | IndexedDB `readx-slack` 保存正文、图片及章节，不经过 Go 服务 |
| 配置与凭据 | 数据根配置及 Electron 本机加密凭据；跨机器不能假定加密凭据可直接解密复用 |
| 自定义数据根 | `CBCT_DATA_ROOT` 可与 Electron `userData` 不同，归档必须覆盖两者；数据库中的绝对文件路径需要迁移处理 |

续作已加入带版本的清单、完整性校验、恢复前检查、路径迁移、恢复前检查点和浏览器存储回放，详见 [备份与恢复](backup-and-restore.md)。代码与独立进程测试已覆盖相关路径，真实 Electron 窗口和 macOS 实机操作仍待验证。
